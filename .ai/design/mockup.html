If you get locked out

Safe mode off

Safe mode switches off the moved login address, the request filter, address and country rules and the two-factor requirement, and leaves everything else alone. Keep these two lines somewhere you can find them.

// wp-config.php
define( 'NHRROB_SECURE_SAFE_MODE', true );

# or from the command line
wp nhrrob-secure safe-mode on
wp nhrrob-secure unlock 103.92.84.10
